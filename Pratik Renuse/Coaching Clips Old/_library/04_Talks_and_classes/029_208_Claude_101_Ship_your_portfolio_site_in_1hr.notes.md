# 029_208_Claude_101_Ship_your_portfolio_site_in_1hr · notes
Who: Pratik teaching a live GrowthX masterclass for about 50 members, mostly marketers; participants Shivam, Urja, Vandana, Prajwal, Nitin and Bhavish share screens and ask questions.
Summary: A hands on build session where attendees turn their LinkedIn export and resume into a portfolio site with Claude, restyle it from a reference site, add a gamified RPG version, then ship it with GitHub and Vercel, connect a custom domain and add a Supabase contact form. Along the way Pratik covers Claude projects and context, chat versus Cowork versus Claude Code, version naming, ask versus act modes, the Comet agentic browser and why builders should ship things that move the needle.
Topics: Claude, Cowork, Claude Code, portfolio site, vibe coding, design references and taste, Claude projects and context, gamified site, GitHub, Vercel, custom domain DNS, Supabase contact form, Comet browser, builder mindset, Lovable versus Claude

## Pratik's best moments (clip and site candidates)
- [01:37 to 04:00] The promise: a live URL, a GitHub repo and a builder's mindset; what you can build in a weekend puts you in the top 1% of people building with AI
- [04:46 to 06:17] Why Claude or Codex over Lovable: customization and compounding, and why a GitHub of shipped projects that move the needle now attracts investors and recruiters
- [07:05 to 08:40] Get unstuck by asking Claude, and give the model clusters of context instead of letting it run wild
- [16:43 to 19:02] Chat versus Cowork versus Claude Code: use Cowork with folder access for multi file projects, Claude Code for production grade tools
- [22:11 to 25:19] Taste: stop iterating colour by colour, give Claude a reference site you love and ask it to take the inspiration, not copy it
- [30:58 to 35:00] Claude projects as compounding context: brand guidelines, a short UI reference and your resume in project files, and why a 600 line file burns your tokens
- [38:15 to 39:53] Version your builds as index1, index2, index3 while learning, then turn the style you like into a skill or MD file
- [01:38:46 to 01:40:07] Build skill first, then build things that make money, save money or save time; spend at least three hours a week building with AI
