# Signals Inbox

Raw incoming items land here. They do not stay. Each one gets processed or thrown out.

## The processing rule
For every item, answer:
1. Which [[00 Theses Index|thesis]] does it touch?
2. What does it imply in 10 to 20 years?
3. Which hidden player does it point to (the unknown name)?

If it can't answer all three, it's news, not signal. Delete it.
If it can, file the dated fact into the thesis and the player note, and add a post idea to the backlog if it's fresh.
