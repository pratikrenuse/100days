## Who they are
Simon Willison is an independent open-source developer, co-creator of the Django web framework, and creator of Datasette and the LLM command-line tool. He has blogged at simonwillison.net since 2002 and is now one of the most prolific, hands-on chroniclers of practical LLM capabilities, tools, and risks.

## Their future thesis (one line)
The near future of AI is about agents (LLMs running tools in a loop to reach a goal) and a shift from "vibe coding" to disciplined agentic engineering, with running, verifiable systems mattering more than model hype, alongside persistent, under-discussed security risks like prompt injection.

## Key future-relevant pieces
- "I think 'agent' may finally have a widely enough agreed upon definition to be useful jargon now" (2025), https://simonw.substack.com/p/i-think-agent-may-finally-have-a
  Lands on a crisp, practical definition: an LLM agent is an LLM that "runs tools in a loop to achieve a goal." Cuts through years of vague "agent" hype with a definition you can actually build and reason against, which matters for predicting what agents will and will not do.

- "Large Language Models can run tools in your terminal with LLM 0.26" (2025), https://simonw.substack.com/p/large-language-models-can-run-tools
  Documents adding tool support to his open-source LLM tool, letting models from OpenAI, Anthropic, Gemini, and local Ollama models call Python functions. A concrete demonstration of where local and agentic tooling is heading, from someone building it in the open.

- "The AI Coding Paradigm Shift" (High Leverage podcast, May 2026), https://www.heavybit.com/library/podcasts/high-leverage/ep-9-the-ai-coding-paradigm-shift-with-simon-willison
  Willison discusses the rapid evolution of AI coding tools, the move from vibe coding to agentic engineering, and how coding agents are reshaping developer workflows. A forward read on how software gets built over the next few years.

- Ongoing blog coverage of frontier model releases (2026), https://simonwillison.net/ (see the llms tag feed: https://simonwillison.net/tags/llms.atom)
  His running, near-real-time notes on each major model (open-weights leaders, new Claude and GPT releases, sandboxed code execution) form the best continuous primary log of what models can newly do. Treat the tag feeds as a live capability tracker rather than any single post.

## Hooks for the brain
- "An agent runs tools in a loop to achieve a goal": the most usable agent definition out there. Anchor it as the brain's working definition.
- Prompt injection and the "lethal trifecta" (Willison's term for combining private data access, untrusted content, and external communication): an under-covered security future that marketers deploying AI tools should understand.
- "Vibe coding" to "agentic engineering": a named transition in how software is made. Good post spine on the future of building.
- Hidden player: open-weights models (he closely tracks the leading open text models). Useful counter to a closed-lab-only view of the future.
