## How to use these

Open the thesis a new item touches. Add it under Evidence (dated). Check whether it confirms, sharpens, or breaks the claim. If it points to a new unknown company, make a [[Players]] note and link it. If awareness on any node tips to mainstream, flag it and hunt a fresher angle.
