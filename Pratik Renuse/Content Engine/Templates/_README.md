# Templates -- the channel adapters

One Story Brief in, one channel-ready draft out. Each template is a fixed set of beats and rules for a single platform, exactly like the LinkedIn Master Template.

The golden rule carries across every channel: **fixed beats, fresh words.** Copy the skeleton, never the sentences. Same voice everywhere: write for a normal person, no jargon, no em dashes, no emojis, real reactions, say each point once, concrete forecast, today/tomorrow shift close.

## The adapters

- **LinkedIn Post.md** -- pointer to the canonical `Futures Brain/Posts/00 The Master Template.md`. That file is the source of truth for the LinkedIn voice and stays where it is so the weekly task keeps working. Both gold-standard posts (GE, Astera) live there.
- **Video Script (HeyGen).md** -- talking-head script for your HeyGen avatar. To be built from the GE and Astera stories. Doubles as the voiceover base for future Reels and Shorts.
- **X Thread.md** -- the story as a thread, with the strongest possible first post. To be built from GE and Astera.

## Not in scope yet
Instagram Reel and YouTube. Added once the three above are proven.

## How voice stays consistent across channels
All adapters inherit the same voice and rules from the LinkedIn Master Template and `Futures Brain/Style Guide.md`. A channel template only changes the **shape** (length, line breaks, how a thread is numbered, what a video says to camera), never the **voice**. If a HeyGen script or an X thread doesn't sound like the GE post, it's wrong.
