# Twist Bioscience -- HeyGen script

Reading the first human genome cost 3 billion dollars and 13 years. Today? About a hundred bucks.

But that's not even the wild part. We've stopped just reading DNA. We've started writing it, from scratch.

DNA is just a code, the instructions for every living thing. For twenty years, we could only read it. Now we can write it too, and design living things like software. Want a new medicine? You just design it, print the DNA, and let cells build it. It's how the COVID vaccine came together in days, from the virus's code on a computer.

And one quiet company prints all that DNA on a silicon chip. It's called Twist Bioscience. Last year it sold 377 million dollars of DNA, up 20%, and the market values it near 6 billion.

Now it gets stranger. DNA is so dense, one gram could hold a room full of hard drives, and it lasts thousands of years. So Twist spun out a company, backed by Jeff Bezos and the CIA's venture fund, to store data inside DNA.

So today, they print DNA to make medicine. Tomorrow, they might store the whole internet in a test tube. Because every living thing already runs on code. It's called DNA, and we're only now learning to write it ourselves.
