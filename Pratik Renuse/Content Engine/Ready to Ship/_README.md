# Ready to Ship

The review gate. Every approved-for-drafting story gets a folder here holding its channel drafts:

```
Ready to Ship/
  GE Vernova - Power is the Ceiling/
    LinkedIn.md
    HeyGen script.md
    X thread.md
  <next story>/
    ...
```

You read each draft, approve, and post by hand. Nothing here publishes itself.

When a story is fully posted everywhere, move its folder to a `Posted/` archive (or mark it done at the top of each file), so this folder only ever shows what's still waiting on you.

## Note
The two live LinkedIn posts (GE, Astera) currently sit in `Futures Brain/Posts/Ready to Post/`. As the multi-channel flow takes over, new stories will be assembled here instead, one folder per story with all channels together. The Futures Brain Posts folder stays as the LinkedIn archive and the home of the Master Template.
